# Working principles

These are optional reminders for applying the session contract. They need no external checkout, private repository or installed skill. The frozen contract, current user authority and target repository policy take precedence.

- Reproduce a reported failure through the public interface before fixing it.
- Prefer the smallest implementation that satisfies the observable outcome.
- Check boundaries and action sequences, including interruption, retry and recovery.
- Keep evidence tied to the source that produced it. Inspect the logs and source behind an external receipt.
- Use independent review to challenge completion claims. A passing command cannot establish arbitrary semantics.
- Preserve history and explain uncertainty. A checkpoint becomes durable only after its destination confirms persistence.
- Park improvements outside the agreed task. Change scope through an authorized linked follow-up.

Record the behavioral evidence in `assess --evidence`. A principle citation is not a test result.
